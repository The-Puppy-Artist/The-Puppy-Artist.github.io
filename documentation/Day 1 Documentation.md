* **Color Palette:** Color palette is chosen via vibe, looked through pinterest and the internet for a retro looking color palette and stumbled upon a palette that reminds me of autumn, I also stumbled upon a color palette that reminds me of retro computers so we went with that, but looking at the UI now, I think the autumn like colors fit more. I had not just the retro aesthetic in mind but also the eyes of the readers and visitors in mind. I have an idea and Imma implement that for this issue.
* **Effects:** Added CRT scanlines effect, but is only a CSS effect, gonna go to javascript and program it to move like a real scanline. Do note this is above the website design layer.
* **Other Features:** Added a time feature, features the time of local wherein its for the reader, then another time for the Philippines, then lastly a time for Japan, I put that there coz I miss Japan and seeing a World clock of it inspires me alot, a simple gesture in a way.
