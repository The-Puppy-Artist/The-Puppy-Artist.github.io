## 1. UI Design and Aesthetic:
* **Icons:** Dynamic Desktop Iconsd added, also adjusted them in the CSS to be big
* **Size up:** UI has been increased in size along with font sizes, especially in blog-window to accomodate 5 rows or columns of folders or something 
* **Retro Reading Template:** Made a retro template to be reused for blog or log entries.
* **Menu Bar Formatting:** Applied flex box rules to prevent navigation bar from breaking onto multiple lines on smaller screens. IE Mobile. 


## 2. Architecture and Workflow:
* **File Structure:** Added more organizational folders
* **Decap CMS:** CMS connection established, also hidden along with git-based admin dashboard, this is where I can write said blogs.
* **Markdown Translation:** integrated marked.js to instatly parse raw .md files generated by CMS into perfectly formatted HTML.
* **GitHub REST API Automation:** Replaced hardcoded HTML links with a dynamic JavaScript fetch function. The Script actively scans for new stuff in content/blog folder and automatically draws clickable desktop icons for every published blog. 


## 3. Issues Faced:
* **Typos and more Typos:** Alotta typos on my part which lead to some confusion  
* **Cache Issue:** Due to the many changes in CSS due to said typos, which are also found in HTML, the cache was very aggresive, had to reset alot. 
* **Dual Hosting DeSync:** Navigated the quirks of running the site concurrently on GitHub pages and Netlify, requiring manual cache clear ups to keep both environments matched.
* **Case Sensitivity:** Due to said typos, 404 errors were numerous earlier.
